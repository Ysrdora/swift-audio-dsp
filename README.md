# AudioDSP

[![CI](https://github.com/ysrdora/swift-audio-dsp/actions/workflows/ci.yml/badge.svg)](https://github.com/ysrdora/swift-audio-dsp/actions/workflows/ci.yml)
[![Swift 6.0](https://img.shields.io/badge/Swift-6.0-orange.svg)](https://swift.org)

High-performance digital signal processing primitives for Swift 6. 
Backed by Apple's `Accelerate` framework and `vDSP`.

## Features
- Hardware-accelerated FFT computation
- Strict concurrency checking for real-time audio thread safety
- Zero third-party dependencies

## Requirements
- Swift 6.0+
- macOS 14+ / iOS 17+
